專案

專案是你電腦上的一個資料夾,所有文字、分鏡、圖片都存在裡面(可自行 git 版控)。需要 Chrome / Edge 等 Chromium 瀏覽器。

模型設定

每一列是一個可用的 API 端點:自架服務或任何 OpenAI 相容 API。key 預設只留在記憶體,關閉分頁即消失;勾「記住」才會存進瀏覽器(此網域與其他 Pages 專案共用儲存空間,共用電腦請勿勾選)。

類型說明:codex-image-service 與 gemini-web 是可自架的開源服務(見 README);OpenAI 相容則填 baseurl / model / key 即可,例如 OpenAI 官方或任何相容閘道。

不想在網頁上填 key?在專案資料夾放一個 keys.json:{"provider 名稱": "key"},開專案時自動帶入(只進記憶體)。若專案資料夾有 git 版控,記得把 keys.json 加進 .gitignore。

章節分鏡

角色庫

每個角色=文字設定卡+設定參考圖。生圖時設定卡必定拼進 prompt;參考圖可逐格勾選附帶,角色長相才會穩定。

生圖

排版匯出

在圖上點一下新增氣泡、拖曳移動、雙擊改文字。氣泡是 HTML 疊字,匯出後在閱讀器裡也是文字(可選取、清晰、可改)。

匯出 PWA 漫畫電子書

匯出到專案的 dist/ 資料夾:一個自包含的離線閱讀站,丟到任何靜態空間(GitHub Pages、NAS、隨身碟)都能看、能安裝到手機桌面。
