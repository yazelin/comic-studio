專案

專案是你電腦上的一個資料夾;文字、分鏡、圖片全部存在裡面,可自行備份或 git 版控。需要 Chrome / Edge 等 Chromium 瀏覽器。

模型

每一列是一個 API 端點——自架服務或任何 OpenAI 相容 API。key 建議放專案資料夾的 keys.json(開專案自動帶入);網頁上填的 key 預設只留在記憶體。

分鏡

匯入或貼上章節文字,AI 切成分鏡腳本後逐格編修。畫面描述是給生圖模型看的,寫得越具體越好。

角色

每個角色=文字設定卡+設定參考圖。設定卡必拼進每格 prompt;參考圖讓長相穩定。建議先建好角色再跑分鏡,AI 會直接用角色 id。

生圖

逐格生成或整章批量;點候選圖可放大,按「選定」的才會進排版與匯出。

排版

三層合成:底圖(不動)→ 效果層 → 字層。氣泡=文字疊圖(拖曳移動、雙擊編輯、圖上點一下新增);效果層=CSS 做不出的表現(畫出來的擬聲字、光暈、煙)——「＋效果層」生成或上傳,墨(白底×multiply)/光(黑底×screen)免摳圖,拖曳移動、雙擊調整、右鍵刪除。調完記得儲存。

匯出

預設走 CSS 疊字(排版即成品,字體一致、改字零成本)。只有特殊表現格才用整格重繪——效果字、文字要跟畫互動的格:單格按「重繪」把文字畫進圖,自動帶字體錨。匯出電子書時有重繪圖的格用重繪圖,其餘用選定圖+疊字。

匯出 PWA 漫畫電子書

已重繪的格用重繪圖(文字在圖裡);還沒重繪的格用選定圖+疊字。寫進專案的 dist/:自包含離線閱讀站,丟任何靜態空間就能看、能安裝到手機。
